# Game3121

**Unity Create-with-Code style challenge work** (endless runner / obstacle spawn flow) from a Game3121 course commit.

---

## Status

Educational repository. Single initial commit. The tree currently also tracks Unity `Library/` package cache content, which is not ideal for a portfolio clone — treat `Assets/Challenge 3/` as the meaningful authored area.

| Language | **C#** |
| Input | Unity Input System action assets |
